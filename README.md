# 💻 Projetos Curtos Front-End

Este repositório contém diversos mini projetos desenvolvidos para praticar HTML, CSS e JavaScript, **com desafios e materiais repassados pela [CodiAcademy Juiz de Fora](https://www.codiacademy.com.br/)**. Cada pasta corresponde a um projeto independente, focado em consolidar conceitos aprendidos durante o curso.

---

## 📂 Vitrine de Projetos

Abaixo, você encontra a lista de projetos desenvolvidos, organizados por categoria e tecnologias.

| Projeto | Descrição | Tecnologias |
| :--- | :--- | :--- |
| **🔍 Buscar CEPs** | Consumo da API BrasilAPI para localização de endereços. | `JS` `API` `CSS` |
| **🎮 Jogo da Velha** | Clássico jogo interativo com lógica de vitória/empate. | `JS` `DOM` `CSS` |
| **🛍️ Shopify Clone** | Interface inspirada no layout da Shopify. | `HTML` `CSS` |
| **📺 YouTube Home** | Clone simplificado da página inicial do YouTube. | `HTML` `CSS` |

### 🎨 Clones com Tailwind CSS

## ▶️ Como Explorar

Cada pasta neste repositório é um projeto **autônomo**. Para visualizar:

1.  Faça o download ou clone o repositório: 
    `git clone https://github.com/seu-usuario/projetos-frontend.git`
2.  Navegue até a pasta desejada.
3.  Abra o arquivo `index.html` (recomendo usar a extensão **Live Server** do VS Code para a melhor experiência).
